# Reels Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce a 30 s and a 15 s vertical (1080x1920) reel from the real rideff.com that shows off the UI (Build-page particles first) and sells the 15-min call.

**Architecture:** Node `.cjs` scripts under `scripts/reels/` drive the built site with Playwright using a deterministic frame clock (N frames = fps x duration, independent of wall time), render text overlays from HTML, synthesize a beat with ffmpeg, and compose everything with ffmpeg. Output goes to `reels/out/` (git-ignored). The site source is not modified.

**Tech Stack:** Node 22, Playwright 1.63 (preinstalled globally; `require('playwright')` works from any directory, so use `.cjs`, do not add it to `package.json`), ffmpeg/ffprobe 6.1, `node:test`.

**Spec:** `docs/superpowers/specs/2026-11-25-reels-design.md`

## Global Constraints

- Output 1080x1920, 30 fps, H.264 `yuv420p`, AAC audio; cuts: 30 s and 15 s (tolerance 0.2 s).
- On-screen text English; subtitles German (formal "Sie" if addressing). Music only, no voiceover.
- Zero paid credits: no ElevenLabs/Higgsfield calls. Block `*.elevenlabs.io` and `api.elevenlabs.io` in every Playwright context.
- Do not change the website's source, copy or dependencies. Output only in `scripts/reels/` and git-ignored `reels/out/`.
- No `[...]` placeholder text and no price figure ("3.000", "8.000", "€") in any frame or overlay copy.
- Brand tokens: orange `#FF6A00`, dark `#14080A`, light `#FFF7ED`.
- Build with `npm ci && npm run build && npm start` (production, port 3000); do not capture from `next dev`.
- Particle count must be 26000 (label "26000" in hero), i.e. viewport width >= 760.
- Do not commit unless the owner asks; "Commit" steps below mean prepare the message only if asked. (Repo rule: commit only on request.)

## Review Focus

- Slow software WebGL makes capture wall-time long: video length must still equal frames/fps (test frame count, not time).
- Hero shows 9000 particles (small viewport) instead of 26000: reel would look sparse. Assert the label.
- Placeholder `[...]` or unconfirmed price visible in a frame or overlay: scan DOM text of every captured page and overlay copy.
- Nana in the frame triggers real ElevenLabs traffic (credits) or shows an error: assert zero requests to ElevenLabs hosts; Nana uses mock answers.
- German subtitle too long and clipped at 1080 px: cap characters per line and measure overlay bounding box.
- Music clipping/too quiet: check peak level.
